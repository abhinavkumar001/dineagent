# Dish photos (optional)

Every dish already has a drawn illustration. To show a real photo instead, put a JPG here named after the
dish's item id from `src/main/resources/data/catalog.json`, for example:

    i401.jpg   Masala Dosa
    i701.jpg   Hyderabadi Chicken Biryani

Use your own photos or ones with a licence that allows reuse (for example Unsplash or Pexels), ideally 600×520 px.
The app falls back to the illustration automatically if a file is missing.
